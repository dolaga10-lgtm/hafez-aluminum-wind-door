# تطبيق الورشة الذكية المخصص (إصدار خاص بدون إعلانات)

مشروع تطبيق أندرويد متكامل مبني بإطار العمل **Flutter** ومجهز لبناء ملف `APK` تلقائياً عبر **GitHub Actions**.

## المميزات المنفذة في هذه النسخة

1. **إضافة قطاعات جديدة مخصصة بالاسم والصورة والأجزاء:**
   - إمكانية إضافة أي قطاع جديد وتسميته واختيار صورة له من الاستوديو أو الكاميرا.
   - إضافة أجزاء القطاع بحرية كاملة (**حلق، ضلفة، سكينة، منخل، أو أي جزء إضافي**) وتحديد معادلة التخصيم لكل جزء و**عدد القطع المضافة لكل شباك** (ثابت أو مضروب في عدد الضلف).
   - شاشة معاينة فورية داخل نافذة إنشاء القطاع لاختبار مقاسات القص والعدد قبل الحفظ.
   - حفظ القطاع تلقائياً ليظهر بالاسم والصورة في قائمة القطاعات.

2. **حذف الإعلانات وسوق شراء الخامات بالكامل:**
   - التطبيق نظيف تماماً وخالٍ من أي إعلانات (`AdMob` / `Facebook Ads`) ومن متجر شراء الخامات، ويعمل بالكامل بدون إنترنت (`Offline-First`).

3. **قائمة التسعير الخارجية الشاملة:**
   - شاشة مستقلة لتحديد **سعر المتر المربع لكل قطاع**.
   - قائمة لتسعير **أنواع الزجاج** (سعر المتر المربع لكل فردة زجاج).
   - تسعير **الزجاج الدبل**: عند اختيار زجاج دبل لشباك العميل، يحسب التطبيق تلقائياً **(ثمن الفردة الأولى + ثمن الفردة الثانية + ثمن السبيسر المحيط بينهما)**.
   - تسعير مستقل لأعواد **الجورجيا** بالمتر الطولي.

4. **سجل العملاء وإصدار 2 ملف PDF لكل عميل:**
   - حفظ جميع العملاء في سجل دائم داخل التطبيق مع إمكانية البحث والرجوع لأي عميل وتعديل مقاساته أو شبابيكه في أي وقت.
   - توليد ومشاركة **ملفي PDF** باللغة العربية لكل عميل بضغطة زر:
     1. **`عرض_سعر_<اسم_العميل>.pdf`**: كشف عرض السعر المالي المفصل للعميل.
     2. **`كشف_طلبية_وتخصيم_<اسم_العميل>.pdf`**: كشف الطلبية الشامل للورشة والتاجر (مقاسات قص القطاعات وعدد كل جزء + مقاسات وأنواع الزجاج الفردي/الدبل والسبيسر والجورجيا + جدول تقسيم الأعواد 600 سم وتقليل الهالك).

5. **تقسيم الأعواد (600 سم) وتقسيم الألواح:**
   - خوارزمية تقسيم الأعواد القياسية (600 سم) مع خصم سُمك صينية المنشار، وتقسيم ألواح الخشب والفايبر.

## طريقة رفع المشروع على GitHub واستلام ملف الـ APK تلقائياً

1. فك ضغط ملف `Smart_Workshop_GitHub_Project.zip` على جهازك.
2. أنشئ مستودعاً جديداً (New Repository) على حسابك في **GitHub**.
3. ارفع جميع الملفات والمجلدات الموجودة داخل المجلد (بما فيها مجلد `.github/workflows/build_apk.yml` ومجلد `lib` و`assets` وملف `pubspec.yaml`).
4. بمجرد رفع الملفات، ادخل إلى تبويب **Actions** في مستودعك على GitHub، ستجد عملية البناء (**Build Smart Workshop Android APK**) قد بدأت تلقائياً (تستغرق حوالي 3 إلى 4 دقائق).
5. بعد انتهاء البناء باللون الأخضر، ستجد ملف **`Smart_Workshop_Custom_Release.apk`** جاهزاً للتحميل مباشرة في قسم **Releases** على يمين صفحة المستودع، وكذلك داخل تبويب **Actions -> Artifacts**.
